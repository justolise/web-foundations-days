About QuickNotes

QuickNotes is a simple website for capturing ideas the moment they happen. It helps you write, organise and find your notes without any difficulty.

How to use QuickNotes

  1. Open QuickNotes and go to Add a note section.
  2. Type your note in the text area.
  3. Press Add Note button to save the note.
  4. Find your notes in Your notes section.

Features

  • Create notes quickly
  • View and read your notes
  • Keyboard shortcuts for common actions
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + V View your notes
